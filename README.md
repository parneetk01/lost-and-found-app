# 📱 Lost & Found Android App

## 📌 Description
This is a simple Android application that helps users manage lost and found items. Users can add item details such as item name and owner name, and view them in a list.

## 🚀 Features
- Add lost/found items
- Store item details
- View items in list format
- Simple and user-friendly interface

## 🛠️ Technologies Used
- Android Studio
- Java
- XML
- SQLite (if used)

## 📦 Deployment
The application is deployed using GitHub Releases.  
APK file is available for download and installation.

## ▶️ How to Use
1. Download APK from Releases section  
2. Install on Android device  
3. Open app and start adding items
